# OpenFEP M18.2 Work Prompt

## Milestone

M18.2: Addressee And Target-Resolution Graph

## Goal

Make Path B explicitly reason about:

```text
who is speaking
who is being addressed
who is being talked about
who a pronoun or alias currently points to
```

without collapsing everything into one `target_person`.

This milestone consumes the participant contract from M18.1. It does not invent
participant identity or transcript persistence on its own.

## Required Work

### 1. Replace single-target binding with a bounded graph

Introduce a bounded group-turn binding object, for example:

```text
GroupTurnBinding:
  current_speaker
  addressed_participants
  mentioned_participants
  candidate_targets
  pronoun_bindings
  ambiguity_band
  conflict_flags
```

The graph should be derived from bounded structured inputs when available:

- speaker participant ref
- reply-to linkage
- explicit mentions / quotes
- bounded recent transcript ownership from M18.3
- bounded runtime interpretation fields

### 2. Support reply-to ambiguity honestly

If addressee ambiguity is high, Path B must be able to clarify instead of
pretending certainty.

### 3. Separate "current speaker alias" from "third-party target"

Alias protection must still hold in group conditions.

### 4. Keep bounded structured inference

Do not solve this with regex cue piles.
Any semantic resolution beyond mechanical validation must come from bounded LLM
fields or equivalent structured interpretation.

### 5. Declare graph bounds explicitly

At minimum, the spec must state:

- maximum active participants considered per turn
- maximum candidate targets retained
- how ambiguity bands are mapped to clarify vs proceed
- how reply-to evidence outranks weak lexical cues

## Acceptance

This milestone is complete only if:

- the runtime can represent more than one candidate target in the same turn
- explicit addressee, quoted third party, and pronoun inheritance can be
  distinguished
- ambiguous turns can trigger clarify rather than wrong confident answers
- reply-to or quote linkage, when present, outranks weak name/pronoun drift
- there is at least one regression with three named participants
