# OpenFEP M14.5 Work Prompt

## Milestone

M14.5: Production Proactive Policy Hardening

## Goal

After M14.4 proves open-page implicit idle delivery, restore conservative
product guardrails for non-demo deployments without removing the Streamlit wiring.

M14.5 is the **policy rollback + operator controls** milestone. It does not
re-remove the implicit idle tick; it re-applies bounded caps by default and makes
profile selection explicit.

Target posture:

```text
Default proactive_policy_profile = bounded_default
implicit_idle_delivery = false by default for new installs
streamlit_open_chat available only via explicit dev toggle or env flag
session cap, cooldown, and assessor gates documented in operator runbook
```

## Dependencies

- M14.4 Streamlit implicit idle proactive delivery (wired path must exist)
- M13.3 initiative evaluator
- M14.3 suppression taxonomy (recommended; may land before or after M14.5)

## Non-Goals

- Do not remove implicit idle Streamlit integration added in M14.4.
- Do not add push notifications or new outreach stacks.

## Required Work

### 1. Default Profile Reversion

```text
default_initiative_state():
  implicit_idle_delivery = false
  proactive_policy_profile = "bounded_default"
  max_proactive_per_session = 1 (unchanged)
```

New MVP sessions use conservative defaults unless user opts in.

### 2. Operator Controls

Sidebar / config:

```text
- proactive opt-in remains explicit
- implicit idle delivery subordinate to opt-in, default off
- policy profile default bounded_default
- dev mode banner when streamlit_open_chat active:
    "Demo profile: session/cooldown caps disabled"
```

### 3. Rate Limit Recommendations

Document recommended production values:

```text
max_proactive_per_session = 1
cooldown_turns = 2
idle_threshold_seconds >= 120
implicit idle attempt throttle >= 45s
```

### 4. Regression Tests

```text
test_fresh_session_uses_bounded_default_profile
test_implicit_idle_delivery_false_by_default
test_streamlit_open_chat_only_via_explicit_setter
test_m14_4_wiring_still_calls_implicit_idle_when_profile_enabled
```

## Acceptance Criteria

1. Fresh install behavior matches M13.3 conservative contract.
2. M14.4 wiring remains functional when profile explicitly set to `streamlit_open_chat`.
3. Operator doc explains how to enable demo vs production profiles.

## Definition Of Done

- `reports/m14_5_proactive_policy_hardening.md` documents defaults and flags.
- Tests pass; README/CLAUDE updated.
